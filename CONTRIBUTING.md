# Contributing

Thank you for helping improve the Cavuno API contract and documentation.

## Issues

Use issues for documentation problems, inconsistent schemas, missing examples,
and proposals for public API behavior. Do not include API keys, access tokens,
customer data, private endpoints, or vulnerability details.

Report vulnerabilities privately as described in `SECURITY.md`.

## Pull requests

`openapi.json` is generated from Cavuno's public API allowlist and must not be
edited by hand. Pull requests may improve repository documentation and
examples. Product or contract changes should start as an issue so the service,
contract, docs, SDK, CLI, and MCP behavior can change together.

By submitting a contribution, you agree that it may be distributed under the
MIT License and that you have the right to submit it.
